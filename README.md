🔐 Task 01: Caesar Cipher Encryption and Decryption – Project Overview


📌 Objective
The objective of this task is to create a program that encrypts and decrypts text using the Caesar Cipher algorithm.
The program allows users to enter a message and a shift value to securely transform plain text into cipher text and convert it back to the original message.


🛠 Tools & Technologies Used
Python – Programming language
Google Colab – Development and execution platform
GitHub – Code hosting and version control.

⚙️ How the Project Works
The user enters a text message.
The user provides a shift value (key).

For encryption:
Each letter in the message is shifted forward by the given shift value.

For decryption:
Each letter is shifted backward using the same shift value.
Non-alphabet characters (spaces, numbers, symbols) remain unchanged.
The program displays the encrypted or decrypted output.

🔑 Key Features:
Supports both encryption and decryption
User-defined shift value
Preserves spaces and special characters
Simple and easy-to-use interface.

🔐 Cybersecurity Relevance:
The Caesar Cipher is one of the earliest encryption techniques and helps in understanding:
Basics of cryptography
Substitution ciphers
Role of keys in encryption
This task builds a foundation for learning modern encryption algorithms used in cybersecurity.
